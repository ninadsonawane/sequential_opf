# Sources and attribution

The numerical solvers in this repository were independently implemented.
No author solver, paper PDF, installed library binary, or MatACDC source program
is included. Dependencies are installed separately and retain their own licenses.

- **P3:** Kim, Nguyen & Santoso, *A sequential power flow algorithm for
  multi-frequency HVac systems and VSC-HVdc systems*, 2026,
  DOI [10.1016/j.ijepes.2026.112025](https://doi.org/10.1016/j.ijepes.2026.112025).
  Source of the topology, methodology and reported numerical comparison targets.
- **P1:** Nguyen & Santoso, *Optimal Planning and Operation of Multi-Frequency
  HVac Transmission Systems*, IEEE TPWRS 36(1), 2021,
  DOI [10.1109/TPWRS.2020.3037967](https://doi.org/10.1109/TPWRS.2020.3037967).
  Source of the planning/operation objective structure and comparison design.
- **Stagg / El-Abiad five-bus benchmark:** original case examined via the
  [KU Leuven MatACDC distribution](https://www.esat.kuleuven.be/electa/teaching/matacdc).
  MatACDC restricts software redistribution; its `.m` program and archive are
  not vendored. Bundled JSON contains our numerically reconstructed hybrid case
  and disclosed modifications, not the downloaded source program. Cite the
  original benchmark and MatACDC in research using this reconstruction.
- **IEEE cases:** obtained through [PYPOWER](https://github.com/rwl/PYPOWER),
  independently checked against Newton PF. PYPOWER is installed as a dependency
  and is GPL-licensed. Its source code is not copied into this repository.
  Original IEEE benchmark provenance is described by PYPOWER/MATPOWER.
- **NumPy, SciPy, Numba, llvmlite and Matplotlib:** installed dependencies;
  consult their distributions for licenses. LLVM/BLAS implementations and
  numerical library versions affect execution and floating-point behavior.

Paper table values are factual numerical comparison targets. They are not used
to fit the reconstructed electrical inputs. Original figures and article text
are not redistributed. All plotted figures here are generated by our code.

The independently authored source has no new blanket license grant in this
initial release. Contact the repository owner regarding reuse permissions;
dependency licenses and original source attribution remain applicable.
